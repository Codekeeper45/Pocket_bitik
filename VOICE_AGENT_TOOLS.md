# Голосовые инструменты агента

В `/ask` и включённом владельцем `/auto_reply` модель может искать голоса Fish Audio, выбирать голос и отправлять текстовые или голосовые ответы на конкретные сообщения текущего чата.

Нужны `FISH_AUDIO_API_KEY`, доступный Fish TTS и ffmpeg с libopus. Используется существующий `FISH_TTS_MODEL`, по умолчанию `s2.1-pro-free`. Качество и задержка зависят от Fish Audio. Бесплатный тариф имеет ограничения.

## Инструменты

- `fish_voice_search`: поиск по названию/стилю и коду языка (`ru`); `source=favorites` показывает существующие избранные голоса. Результат содержит `voice_id`, название и языки. Метаданные не заменяют прослушивание.
- `fish_voice_select`: проверяет ID голоса и сохраняет его только для текущего чата в `voice_chat_defaults.json`.
- `send_chat_responses`: список ответов. Каждый содержит `text`, `mode=text|voice`, необязательные `message_id` и `voice_id`. ID сообщения должен быть прочитан в текущем контексте. Без ID отправляется обычное сообщение в текущий чат.
- `reply_to_messages`: прежний инструмент реплаев дополнен полями `mode` и `voice_id`; текстовый режим и выделение цитат сохранены.

Для смены голоса на один ответ достаточно передать `voice_id`. Глобальный `/voice fish` и другие чаты не изменяются. Перезапуск не нужен. В пределах одного вызова агента общий бюджет отправки составляет 10 ответов; голосовой текст ограничен 1800 символами. Голос отправляется как Telegram voice note OGG/Opus.

Агент выбирает формат по смыслу, может сочетать голос и текст. Прямую просьбу ответить текстом должен учитывать. `/ask -v` принудительно направляет ответы новых инструментов в голос. Флаг `/ask -t` по-прежнему относится к входному контексту, а не к запрету голосового вывода. Прежние ручные команды `/voice` остаются.

После отправки инструментом финальный дубль ответа не публикуется. Ошибки Fish, неверный голос или неизвестный ID возвращаются модели как ошибки: она может исправить запрос или ответить текстом. Указанный голос не подменяется молча другим движком. Адресат ограничен текущим чатом; голоса берутся из каталога, клонирование здесь не выполняется.

## Расширенный каталог

`fish_voice_get(voice_id)` открывает карточку по точному ID. `fish_voice_search` принимает `voice_id` или ID в `query`, `title`, `description`, `language`, `tags`, `author_id`, `licensed`, `min_likes`, `min_uses`, `sort_by`, `page`, `scan_pages`, `limit`.

Карточка содержит описание, теги, языки, автора, лайки, сохранения, использования, публикации, доступные данные quality и ссылки на образцы. Отсутствующие показатели возвращаются null, не придумываются. Лайки и использования являются популярностью, а не оценкой качества по звёздам.

Fish поддерживает серверный поиск по title, language, tag, author_id и licensed, сортировки score/task_count/created_at. Поиск description и минимумы популярности выполняются по просмотренным страницам (до 5 за вызов, до 250 кандидатов); like_count/mark_count сортируются только внутри просмотренной выборки. Пустой результат не означает отсутствие голоса во всей базе. Инструмент возвращает охват, upstream_has_more, next_page и признак точности общего количества Fish. Менять размер страницы при продолжении обхода не следует: номер страницы Fish зависит от page_size.
